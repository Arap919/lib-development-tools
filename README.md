# @ff/local-development-tools

Этот проект содержит инструменты для локальной разработки, которые упрощают процесс сборки, публикации и подключения библиотек с использованием `ng build`, `yalc` и других инструментов.

## Установка

1. Установите пакет:

```bash
npm install local-development-tools --save-dev
```

## Скрипты

1. local-watch-and-link

Этот скрипт предназначен для локальной сборки библиотеки и автоматического подключения её в основной проект с использованием yalc.

Использование:
```
build-and-link <путь_к_проекту>
```
где:
*	<путь_к_проекту> — путь до основного проекта, в который будет добавлена библиотека.

Что делает скрипт:
*	Сборка библиотеки с помощью команды ng build --watch.
*	Ожидание появления сборки.
*	Публикация библиотеки с помощью yalc.
*	Подключение библиотеки в основной проект.

2. push-local-changes

Этот скрипт используется для пуша локальных изменений библиотеки в реестр yalc.
```
npx push-changes
```
Что делает скрипт:
*	Получает путь к библиотеке из директории, в которой скрипт запускается.
*	Публикует изменения с помощью команды yalc push.

## Пример конфигурации
Пример package.json библиотеки

```json
{
  "name": "test-lib",
  "version": "0.0.0",
  "scripts": {
    "build-some-library": "ng build test-lib",
    "local-watch-and-link": "build-and-link /Users/olegfirskov/test-project",
    "push-local-changes": "push-changes"
  },
  "devDependencies": {
    "@ff/local-development-tools": "0.0.1"
  }
}
```
